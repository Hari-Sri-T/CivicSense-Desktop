# Civic Sense logo

Primary asset: `static/civicsense-logo.png` (transparent PNG, 1254 × 1254).

Created using the built-in image generation tool. The original generated image is preserved; the application uses a workspace copy. The blue document/initial monogram appears on the startup screen, beside the application name, and as the favicon. Qt/GTK desktop windows also use it as their icon. Wordmark text is rendered by the interface for clarity at different text sizes.

The startup screen follows the model runtime's actual state. It dismisses when the models are ready, shows download/load messages, and provides retry and model-settings actions if preparation fails. The progress animation is indeterminate, not an estimated completion percentage. Users who prefer reduced motion see a stationary indicator.

## Generation prompt

Use case: logo-brand. Asset type: an original logo symbol for Civic Sense, a local desktop application that helps people understand civic and legal documents. Create ONE polished, distinctive geometric C/S monogram, combining an open letter C with an S-shaped negative-space path that subtly suggests a folded document and two lines of readable text. The mark should feel like established desktop software: precise, restrained, functional, memorable at small sizes. Flat vector-like shapes with deliberate proportions, consistent optical weight, crisp edges. Color palette: a single medium blue close to #5797F6 with a small cool light-grey detail close to #D9DEE5; dark interface use. Center a single large symbol with a little clear padding on a square TRANSPARENT canvas. All negative space and the entire backdrop must be genuinely transparent. No lettering, no words, no slogan, no presentation board, no mockups, no shadows, no glow, no gradients, no 3D, no sparkles, no neural-network motif, no generic shield, no scales of justice, no stock courthouse. Deliver only the finished single logo emblem.
